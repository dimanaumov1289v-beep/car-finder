# АвтоПоиск

Учебное веб-приложение, которое подбирает автомобили по описанию на русском языке: **«красивая Toyota»**, **«недорогая машина»**, **«кроссовер до 3 млн»**.

Python + Flask, SQLite, HTML и CSS. Поиск работает локально по словарям и правилам. Для запросов не нужны ключи API, нейросети, CDN или VPN. Это ограниченный словарный разбор русского языка, а не полноценное понимание произвольной речи.

## Возможности

- Поиск по маркам и моделям, странам, кузову, топливу, бюджету и описательным словам.
- Объяснение распознанных условий. Непонятные слова и отрицания не игнорируются: пользователь получает подсказку.
- Сортировка по цене, мощности и дизайну с сохранением запроса.
- Избранное в подписанной cookie текущего браузера.
- Оценки дизайна от 1 до 5, средний балл и число голосов; повторный голос заменяет предыдущий.
- Постоянная SQLite-база: голоса сохраняются после перезапуска при сохранении файла БД.
- Адаптивный интерфейс, доступные названия элементов и формы, работающие без JavaScript.

## Быстрый запуск

Нужен установленный Python 3.11 или новее. Проверено на Python 3.13.5. Выполняйте команды из распакованной папки проекта.

### Windows (PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe main.py
```

`py` — запуск установленного Python. `-m venv` запускает модуль создания виртуального окружения; `.venv` — имя папки окружения. Затем используется Python именно из этой папки. `-m pip` запускает установщик пакетов; `install` устанавливает зависимости, `-r requirements.lock` читает их из указанного файла. `main.py` — файл приложения, переданный Python для выполнения. При повторном запуске достаточно последней команды.

### macOS / Linux

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python main.py
```

`python3` — интерпретатор Python 3. Смысл `-m`, `venv`, `.venv`, `pip`, `install`, `-r` и `main.py` описан выше. Отличается путь к Python внутри окружения. Активация окружения не требуется.

Откройте **http://127.0.0.1:5000**. `127.0.0.1` — этот компьютер, `5000` — порт приложения. Остановка сервера: `Ctrl+C` в терминале. При первом запуске установке пакетов нужен интернет; после установки локальная работа приложения обходится без сети. Браузер и терминал с сервером должны оставаться открыты.

## Как работает подбор

| Запрос | Условие |
|---|---|
| красивая / стильная | Оценка дизайна ≥ 4; по умолчанию выше лучший балл |
| мощная / быстрая | Мощность ≥ 300 л.с.; это упрощение, а не измерение разгона |
| недорогая / бюджетная | До 1 500 000 ₽, если не задан явный верхний бюджет |
| премиум / дорогая | От 5 000 000 ₽ |
| семейная | Кроссовер, внедорожник или универсал |
| для города | Седан, хэтчбек или кроссовер |
| до 2,5 млн / от 800 тысяч | Верхняя / нижняя граница цены |
| от 1 до 2 млн | Обе границы; единица «млн» относится к двум числам |
| Toyota или Honda | Любая из двух марок |
| красивая Toyota Camry | Марка, модель и оценка учитываются одновременно |

В разных группах действует логическое И, внутри группы — ИЛИ. «Семейная» не проверяет количество мест или безопасность, потому что таких данных в базе нет. «Экономичная» сообщает об отсутствии данных о расходе. Отрицания («не», «без», «кроме») пока не поддерживаются. Русские марки распознаются по словарю; модели вводятся как в каталоге, преимущественно латиницей. Для пустого запроса показывается весь каталог.

Рейтинг: если голосов нет, используется явно помеченный демонстрационный балл автора исходной базы. Если есть хотя бы один голос, используется `сумма оценок / число голосов`; демобалл в эту сумму не входит. Один идентификатор браузерной сессии может иметь одну оценку модели. Cookies можно очистить, поэтому защита от повторного голосования ограниченная. На защите нельзя называть эти данные репрезентативным мнением всех людей.

## Данные и хранение

`data/cars.json` — исходный учебный набор из 32 моделей, перенесённый из первоначального проекта. Цены и характеристики не проверены как актуальные; поколения и комплектации не указаны. Эти данные нельзя использовать как основание для покупки. В интерфейсе больше нет вымышленных ссылок на конкретные объявления.

При запуске создаются `instance/cars.sqlite3` (таблицы `cars`, `ratings`) и `instance/cars.key` (случайный секрет подписи сессий, если не задан `SECRET_KEY`). Они исключены из Git. Не удаляйте их между запусками. Новые ID из JSON добавляются автоматически; существующие записи не перезаписываются. Чтобы обновить существующие характеристики, нужна отдельная миграция данных. Не удаляйте БД с настоящими голосами ради обновления каталога.

При смене ключа сессий избранное и идентификаторы голосующих в браузере сбрасываются; сами оценки в БД сохраняются. Для резервного копирования остановите приложение и сохраните файл БД и ключ отдельно от публичного репозитория.

## Публикация на хостинге

GitHub хранит код, но **GitHub Pages не запускает Flask**. Нужен хостинг с Python/WSGI или VPS. Адрес старого опубликованного сайта в исходном репозитории не указан: причину его работы только через VPN по одному коду установить нельзя.

Для Linux-хостинга с переменной `PORT` предусмотрен `Procfile`. Команда запуска:

```sh
gunicorn --bind 0.0.0.0:$PORT --workers 1 --threads 4 main:app
```

`gunicorn` — сервер Python WSGI для публикации (для Windows используйте локальный запуск выше). `--bind` задаёт адрес и порт: `0.0.0.0` принимает соединения на всех интерфейсах, `$PORT` подставляется из окружения хостинга. `--workers 1` запускает один процесс, `--threads 4` — четыре потока обработки запросов. `main:app` означает объект `app` из модуля `main.py`. Если хостинг не задаёт `PORT`, замените `$PORT` на свободный порт, например `8000`. Внешний доступ к приложению публикуйте через HTTPS в панели хостинга или обратном прокси.

Команда установки на хостинге: `python -m pip install -r requirements.lock`; смысл параметров описан в быстром запуске. На платформах с автоматической установкой из `requirements.txt` также поддерживаются ограниченные диапазоны версий. `requirements.lock` фиксирует проверенные версии всех зависимостей.

| Переменная окружения | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `5000` для локального запуска | Порт сервера |
| `DATABASE_PATH` | `instance/cars.sqlite3` | Путь к SQLite; на хостинге укажите **постоянный диск** |
| `SECRET_KEY` | Сгенерированный файл рядом с БД с расширением `.key` | Постоянный секрет подписи сессий |
| `COOKIE_SECURE` | Выключено | Значение `1` разрешает передачу cookie только через HTTPS |

`.env.example` служит подсказкой: `.env` автоматически не загружается. Не публикуйте реальные секреты. На хостинге с временным диском голоса пропадут при пересоздании приложения: нужен постоянный том для БД. Проект рассчитан на один экземпляр приложения с локальной SQLite-базой. Для нескольких независимых экземпляров нужна общая серверная БД. Встроенный сервер `main.py` предназначен для локальной демонстрации.

`/health` возвращает JSON со статусом и проверяет чтение БД; этот адрес можно указать как проверку работоспособности в панели хостинга.

## Если сайт открывается только с VPN

Проверьте опубликованный домен с разных сетей (домашняя, мобильная). Если локальная версия работает без VPN, а внешний домен недоступен, правка HTML не исправит маршрутизацию, DNS или ограничения хостинга. Для установления причины нужны адрес сайта и точная ошибка браузера. Выбирать и оплачивать другой хостинг до такой проверки не стоит. Для защиты используйте локальный запуск как независимый от доступности хостинга вариант.

## Проверки

```sh
.venv/bin/python -m unittest discover -s tests -v
```

`-m unittest` запускает стандартный модуль тестирования Python; `discover` находит тесты автоматически, `-s tests` задаёт каталог поиска, `-v` включает подробный вывод. В Windows замените путь интерпретатора на `.\.venv\Scripts\python.exe`.

Тесты проверяют смешанные запросы, бюджеты и диапазоны, сортировку, неизвестные слова, отрицания, постоянство рейтинга, замену голоса, избранное, CSRF-защиту, безопасные перенаправления и обработку ошибочных входных данных. Пройдено 19 тестов. Интерфейс также проверен в браузере.

## Структура

- `main.py` — Flask, SQLite, страницы и обработчики форм.
- `search.py` — разбор фраз и применение условий.
- `data/cars.json` — исходные записи.
- `templates/` — общая оболочка, каталог, модель, объяснение и ошибки.
- `static/` — собственные CSS и SVG-иконка; сторонние ресурсы не загружаются.
- `tests/test_app.py` — регрессионные тесты.
- `docs/DEFENSE.md` — объяснение для защиты, схема алгоритма и сигнатуры основных функций.

## Передача изменений в исходный репозиторий

В комплекте исправленной версии может находиться `car-finder-fixes.patch`. Применять его следует к чистой копии исходного репозитория на базовом коммите, указанном в начале патча. Сначала сохраните свои текущие изменения. Альтернатива — перенести файлы из архива в отдельную ветку, сравнить изменения и создать pull request. Папки `.venv`, `instance` и файлы с секретами загружать не нужно.

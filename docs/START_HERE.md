# Памятка: как запустить АвтоПоиск на другом устройстве

Эту памятку можно переслать вместе с архивом проекта. Для запуска нужен компьютер с Windows, macOS или Linux. На телефоне можно открыть сайт, который уже запущен на компьютере в той же сети; способ описан ниже.

## 1. Скачайте проект

Откройте готовую ветку проекта:

https://github.com/dimanaumov1289v-beep/car-finder/tree/fix/natural-language-search

Нажмите **Code → Download ZIP**. Распакуйте архив обычным извлечением файлов. Не запускайте проект внутри ZIP. Откройте папку, где лежат `main.py`, `requirements.lock` и эта памятка в папке `docs`.

Если исправления уже объединены с основной веткой, можно скачать архив с главной страницы репозитория. При передаче через флешку достаточно распакованного проекта; папку `.venv` с чужого компьютера переносить не нужно — её создают заново.

## 2. Установите Python

Нужен Python версии **3.11 или новее**. Проект проверен на Python 3.13.5.

Официальная загрузка: https://www.python.org/downloads/

На Windows, если установщик предлагает **Add Python to PATH**, включите этот пункт. После установки заново откройте терминал. Если Python уже установлен, повторная установка не нужна.

## 3. Откройте терминал в папке проекта

**Windows:** откройте папку проекта в Проводнике, щёлкните по адресной строке, введите `powershell` и нажмите Enter. Откроется PowerShell в нужной папке.

**macOS:** откройте приложение «Терминал», напишите `cd ` с пробелом, перетащите распакованную папку проекта в окно терминала и нажмите Enter. `cd` меняет текущую папку, переданный путь указывает папку проекта.

**Linux:** откройте папку проекта в файловом менеджере и выберите «Открыть в терминале», если такой пункт есть. Либо используйте `cd` с путём к папке, как описано выше.

## 4. Первый запуск

Вводите команды **по одной**, после каждой нажимайте Enter. Дождитесь окончания установки пакетов перед запуском следующей команды.

### Windows — PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe main.py
```

### macOS / Linux

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python main.py
```

Что делают команды:

- `py` на Windows или `python3` на macOS/Linux запускает Python. `-m venv` запускает встроенный модуль создания отдельного окружения; `.venv` — имя создаваемой папки.
- Следующая команда использует Python из этой папки. `-m pip` запускает установщик пакетов; `install` означает установку; `-r requirements.lock` означает чтение списка проверенных версий из файла `requirements.lock` в текущей папке.
- Последняя команда передаёт Python файл `main.py` для выполнения и запускает сайт.

Первичная установка требует интернета. После установки сайт может работать локально без интернета и VPN. Ключи API и регистрация в AI-сервисах не нужны.

## 5. Откройте сайт

В браузере **того же компьютера** откройте:

**http://127.0.0.1:5000**

Не используйте `https://` для этого локального адреса. `127.0.0.1` — текущий компьютер, `5000` — порт сервера. Окно терминала оставьте открытым: закрытие окна остановит сайт.

Проверьте запросы:

- `красивая Toyota`
- `недорогая машина`
- `кроссовер до 3 млн`

Откройте карточку модели, добавьте её в избранное и поставьте оценку дизайна. Демонстрационные баллы помечены «Демо»; после голосования используется среднее посетителей. Данные о машинах и ценах учебные, не актуальные объявления.

## 6. Как запустить снова

Откройте терминал в той же папке проекта и выполните **только последнюю команду** из шага 4. Заново создавать окружение и устанавливать пакеты каждый раз не нужно.

Чтобы остановить сайт, нажмите **Ctrl+C** в терминале.

Не удаляйте папку `instance`: в ней лежат база с голосами и ключ сессий. Избранное хранится в браузере. На другом компьютере с чистой установкой будут отдельные голоса и избранное; они не синхронизируются между независимыми копиями. Для переноса голосов сначала остановите приложение на обоих компьютерах, затем перенесите папку `instance` отдельно и приватно. В публичный GitHub её загружать не нужно.

## Если возникла ошибка

| Что видно | Что сделать |
|---|---|
| `py` или `python3` не найден | Установите Python и заново откройте терминал. На Windows можно проверить `python --version`; если он работает, используйте `python` вместо `py` в первой команде. `--version` выводит установленную версию и завершает команду. |
| На Linux нет `venv` или `pip` | Установите пакеты Python venv/pip средствами своего дистрибутива, затем повторите шаг 4. |
| Не найден `main.py` или `requirements.lock` | Терминал открыт не в папке проекта. Вернитесь к шагу 3. |
| `No module named flask` | Не выполнена установка зависимостей или выбран другой Python. Повторите вторую команду из шага 4 и запускайте Python именно из `.venv`. |
| Ошибка скачивания пакетов | Для первой установки нужен интернет и доступ к Python Package Index. Сохраните точный текст ошибки для диагностики. |
| Браузер пишет «Не удаётся получить доступ» | Проверьте, что сервер ещё работает в терминале, адрес начинается с `http://`, и порт совпадает с сообщением сервера. |
| `Address already in use`, порт занят | Остановите ранее запущенную копию через Ctrl+C или используйте порт 8000 по инструкции ниже. |
| На другом компьютере адрес `127.0.0.1` не открывает этот сайт | Этот адрес всегда означает само устройство. Для просмотра сайта с соседнего устройства используйте инструкцию ниже. |

### Если порт 5000 занят

Windows:

```powershell
$env:PORT = "8000"
.\.venv\Scripts\python.exe main.py
```

PowerShell-присваивание `$env:PORT = "8000"` задаёт переменную окружения `PORT` для текущего терминала и запускаемого приложения; `8000` — выбранный порт.

macOS / Linux:

```sh
PORT=8000 .venv/bin/python main.py
```

`PORT=8000` задаёт переменную окружения только для этой команды. В обоих случаях откройте **http://127.0.0.1:8000**.

## Дополнительно: открыть сайт с телефона или другого устройства в том же Wi-Fi

Этот способ нужен для просмотра одной общей запущенной копии. Компьютер и второе устройство должны находиться в одной доверенной локальной сети. Компьютер с сервером должен оставаться включённым. Это режим короткой учебной демонстрации; для публичного сайта нужен отдельный хостинг и HTTPS.

1. Остановите обычный запуск через Ctrl+C.
2. На компьютере выполните команду:

Windows:

```powershell
.\.venv\Scripts\python.exe -m flask --app main run --host=0.0.0.0 --port=5000
```

macOS / Linux:

```sh
.venv/bin/python -m flask --app main run --host=0.0.0.0 --port=5000
```

Здесь `-m flask` запускает командный интерфейс Flask; `--app main` выбирает приложение из файла `main.py`; `run` включает сервер разработки; `--host=0.0.0.0` разрешает подключения по сетевым интерфейсам компьютера; `--port=5000` выбирает порт. Отладчик не включается. `0.0.0.0` — адрес прослушивания, его не нужно вводить в браузере.

3. В сетевых настройках компьютера найдите его локальный IPv4-адрес. Например, это может быть `192.168.1.25` — у вас будет своё значение.
4. На телефоне или другом устройстве откройте **http://АДРЕС-КОМПЬЮТЕРА:5000**, подставив найденный адрес. Пример: `http://192.168.1.25:5000`.
5. Если система запросит разрешение входящих подключений для Python, разрешите их только для вашей доверенной частной сети. Не отключайте брандмауэр целиком. В гостевых Wi-Fi устройства могут быть изолированы друг от друга; такой просмотр там не заработает.

Снаружи этой сети сайт так не откроется. Для доступа из другого города или через мобильную сеть нужен опубликованный сервер. Доступ к репозиторию GitHub сам по себе сайт не публикует.

## Если нужна помощь

Отправьте преподавателю или разработчику: систему устройства, шаг инструкции, на котором остановились, и точный текст ошибки. Не отправляйте содержимое файлов `.key`, реальные секреты или приватные настройки.
